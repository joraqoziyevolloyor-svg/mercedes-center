GitHub kalitini olish (bir marta)

  1. GitHub'ga kirgan holda oching: github.com/settings/personal-access-tokens/new (nom, muddat va ruxsat oldindan to'ldirilgan bo'ladi, tekshirib chiqing)
  2. Token name: sayt-admin. Expiration: 90 days (yoki Custom, 1 yilgacha). No expiration'ni tanlamang; muddati tugasa, yangisini oling.
  3. Repository access: Only select repositories → mercedes-center.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Generate token ni bosing, chiqqan kalitni nusxalab, yuqoridagi "GitHub kaliti" maydoniga qo'ying.
